# Desempenho

_Atualizado em 2026-11-02._

## Modelo e contexto

- Use um modelo menor (4B a 7B) para tarefas simples.
- Use contexto de 8192 quando der.
- Evite o Cline em tarefas pequenas: o prompt de sistema é enorme.

## LM Studio

- Use 4 threads de CPU.
- Feche o navegador antes de carregar o modelo.

## Energia

- Deixe o notebook na tomada.
- Windows: Configurações > Sistema > Energia e bateria > Modo de energia "Melhor desempenho".
- Dell Power Manager: modo "Ultra Performance".
